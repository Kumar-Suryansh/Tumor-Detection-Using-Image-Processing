# Tumor Detection Using Image Processing

A Python-based brain tumor detection project using medical image analysis and deep learning techniques.

## Overview

This project explores brain tumor detection from MRI images using a Jupyter Notebook. It includes model implementation, image preprocessing, training, evaluation, and explainability-related code.

## Technologies Used

- Python
- Jupyter Notebook
- OpenCV
- Deep Learning
- Convolutional Neural Networks (CNN)
- Vision Transformers (ViT)

## Project Structure


## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/Kumar-Suryansh/Tumor-Detection-Using-Image-Processing.git
   ```

2. Open the project notebook using Jupyter Notebook or Google Colab.

3. Install the dependencies required by the notebook.

4. Configure access to the dataset referenced in the notebook before running the cells.

## Dataset

The notebook references a brain MRI dataset hosted on Kaggle. Dataset access and any required configuration must be set up separately.

## Limitations

The notebook is a project for educational and experimental purposes. Model performance and reproducibility depend on the dataset, configuration, and successful execution of the training and evaluation steps.
